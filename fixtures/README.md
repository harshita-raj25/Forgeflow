# Fixtures — deterministic adapter outputs (execution_mode=fixture)

Everything in this directory is **hand-authored reference material** used by the `FixtureAdapter` for
offline engine tests and rehearsals. It is *not* live model output and every run that uses it is
labeled `fixture` in the UI, events, bundles and summaries.

- `reference/<stage>/` — reference implementations of the URL shortener for stages A, B and C. They exist
  so the engine and the trusted tests can be exercised without a model. They are also the content of the
  fixture implementer responses.
- `<scenario>/<role>[.<task>][.rev<N>].json` — role outputs matching `schemas/<role>.json`. Generated by
  `python fixtures/build_fixtures.py` from the reference implementations. `rev<N>` variants exist where
  the fixture must differ per requirement revision or candidate revision (e.g. Scenario C: 404 then 410).
- `fault/` — fixtures that deliberately produce broken code, used by orchestration tests for bounded repair
  and rollback.

Live scenario evidence must come from `FORGEFLOW_MODE=live` runs; a fixture-only submission must disclose
that live validation is missing.
